# 本面淡墨 vs. 背面透字判读报告

对象：bench 演示合成手稿（Torn manuscript leaf，222×148 mm，正照/透照均为 888×592、四角全幅标定，
已在同一校准平面上）。原 Ink spread 线为 demo 的 “Across blue ink” 样线 (252,196)→(244,346)。

## 1. 数据与圈定窗口

原始两张演示照片本身没有“正照发淡、透照清楚”的透字诱惑层（透照独有的水印环在正照与空纸同色），
为让两种判读策略产生真实分歧，在**派生图**上按物理规律补了一层受控背字，原片未改动：

- 透照侧：三条中性暖灰笔画（RGB 123,111,85，与 demo 水印同族），清晰可见；
- 正照侧：同位置仅 32% 强度的中性暖灰暗化（RGB 目标 96,86,70），无蓝色签名；
- 两块生成器预留的黑色缺拍瓦片原样保留。

派生文件：`work/photos/derived/{face,trans}-derived.png`，脚本 `work/analysis/build_scenario.py`。

| 窗口 | 像素盒 (x0,y0,x1,y1) | 圈定内容（ground truth） |
|---|---|---|
| W_ink | 170,208,265,300 | 已确认本面淡墨：5 条蓝笔画在窗内部分，1 963 px，两照均可见 |
| W_back | 565,160,690,240 | 仅透出来的背字：3 条笔画，1 521 px，两照均可见 |
| W_blank | 520,380,560,420 | 实见空纸，1 600 px，无任何标记 |
| 缺拍瓦片 ×2 | 正照 461,335,478,350（255 px）；透照 425,290,442,321（527 px） | 对应照片 `useful=False`，共 782 px 留作未判 |

已验证三个窗口与两块缺拍瓦片互不相交；本面墨、背字在两照均为有效像素，未判只来自缺拍。

## 2. 量化判据（均为可复算的图像量）

- **正照“像墨”测试（两策略共用）**：正照 Lab（与 bench 同一 `COLOR_RGB2LAB` 管线）相对
  W_blank 空纸中位色 Lab=(78.55, −1.59, 24.50) 的 ΔE76。空纸自身 ΔE 的 p99=2.54；
  本面蓝墨 ΔE 中位 71.9；背字透影 ΔE 中位 12.1（p05=0.92, p95=13.8）。
- **透照“支持像墨”测试（仅策略 B）**：同位置 `useful=True`（看得清、非缺拍）且
  B−R ≥ 0.08——即原 Ink spread 读数使用的蓝墨色度判据。本面蓝墨透照 B−R 中位 +0.239（p05=0.122，
  全部过线）；中性灰背字透照 B−R 中位 −0.149（全部不过线）。
- **缺拍规则**：任一照该像素非 useful → 未判，不参与任何统计。
- **用户限值（本次取值，因题面未给具体数字，按常见验收口径显式声明）**：
  本面淡墨保留比例 ≥ **90%**；背字误判上限 ≤ **8%**。

## 3. 阈值扫描与两套预设

对正照 ΔE 阈值 τ 在 1–30 间扫描（步长 0.25）。两套都满足两条限值的预设：

| 预设 | τ(ΔE) | 取向 |
|---|---|---|
| P1 多保淡墨 | 14.00 | 同时过两条线的最低 τ，最大限度保留淡墨 |
| P2 少认背字 | 15.00 | 保留比例仍为 100% 时、背字误判归零的最低 τ |

## 4. 两种判读的实测结果

| 预设 | 策略 | 本面墨保留 | 背字误判 | 空纸误判 | 结论 |
|---|---|---|---|---|---|
| P1（τ=14.0） | A 仅正照像墨即收 | 1 963/1 963 = **100%** ✅ | 38/1 521 = **2.50%** ✅ | 0.69% | 两条限值都过 |
| P1（τ=14.0） | B 还需透照清晰且支持像墨 | **100%** ✅ | **0%** ✅ | 0% | 两条限值都过 |
| P2（τ=15.0） | A 仅正照像墨即收 | **100%** ✅ | **0%** ✅ | 0.69% | 两条限值都过 |
| P2（τ=15.0） | B 还需透照清晰且支持像墨 | **100%** ✅ | **0%** ✅ | 0% | 两条限值都过 |

四组结果的未判像素一致：782 px（正照瓦片 255 + 透照瓦片 527），全部来自缺拍，未混入任何分子分母。
扫描还显示低 τ 区策略 A 的风险：τ=4 时背字误判 80.7%、τ=8 时 72.3%，即“只看正照颜色像墨就收”
在阈值放松时会大面积吞掉透字；策略 B 在全部 τ 下背字误判恒为 0，因为背字在透照没有蓝墨签名。

叠加图（绿=采纳的本面墨，红=误收的背字，蓝=正确剔除的背字，紫=未判缺拍）：
`work/analysis/results/overlay-P{1,2}-policy{A-face-only,B-dual-check}.png`。

## 5. 只采用一套：P1 + 策略 B（双照复核），取舍说明

**采用：P1（多保淡墨，τ=14.0）配合策略 B（透照复核）。**

- 题目两限值在 P1/P2 下都能过，两套的真正差别只在策略 A：P1 的单照判读法会把 38 个透字像素
  （2.5%）当成墨收下——虽然没破 8% 上限，但这些是已知背字，属本应零容忍的假阳性；
  而同预设下策略 B 不增加任何本面墨损失（保留仍 100%）就把误判清零。
- 不选 P2 的理由：P2 靠把正照阈值再抬高 1 个 ΔE 单位换零误判，受益的只是较脆弱的单照流程；
  在双照复核下 P2 相对 P1 没有任何额外收益（两者 B 的输出完全相同，均为 1 963 个本面墨像素），
  却把正照单侧的判别边界推得更苛，未来遇到更淡的真迹时丢字风险更高。
- 代价：策略 B 依赖透照同位置有效；透照缺拍/遮挡处只能留未判（本次 527 px 即如此），
  不能像策略 A 那样给一个倾向性结论。这是为“背字零误判”付出的合理代价，且与题目
  “缺拍留作未判”的要求一致。

## 6. Paper tone：圈内正照颜色两行（Lab，OpenCV 标度）

只用 W_blank 与 W_back 中**两照都有效**的像素；本面墨（W_ink）与未判瓦片均未混入。
Lab 管线已与 bench 原生 `paperbench.analysis.paper_tone` 在同一空纸窗上交叉核对，分位值一致。

| 行 | 像素数 | L\* p10 / 中位 / p90 | a\* p10 / 中位 / p90 | b\* p10 / 中位 / p90 |
|---|---|---|---|---|
| 实见空纸 | 1 600 | 77.11 / **78.55** / 79.99 | −1.61 / **−1.59** / −1.58 | 24.41 / **24.50** / 24.61 |
| 查明仅为背字的位置 | 1 521 | 65.43 / **67.19** / 77.48 | −1.48 / **−1.03** / −0.50 | 20.33 / **20.73** / 24.00 |

读数解释：背字位置在正照整体更暗（L\* 中位低 11.4）、黄度更低（b\* 中位低 3.8），
但其 p90（L\* 77.48、b\* 24.00）已贴近空纸分布，说明透影淡且不均匀——这正是单看正照颜色
会被诱惑、必须靠透照色度签名才能干净剔除的原因。
